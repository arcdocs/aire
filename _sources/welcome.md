# Aire User Documentation

This site documents information relevant to users of Aire, the High Performance Computing (HPC) facility at the [University of Leeds](https://www.leeds.ac.uk).

Launched on the 6th of February 2025, Aire brought cutting-edge computational power to support research across disciplines. With major upgrades in computing power, memory, and storage, Aire is set to enhance data processing and streamline research workflows.

Users may want to start by reading the [Getting Started](page:getting-started) section.

:::{admonition} Documentation transition
:class: note

With the launch of Calder and the upcoming Aire upgrade, HPC documentation is gradually moving to the new [Leeds HPC User Documentation](https://arcdocs.leeds.ac.uk/calder/welcome.html) site. This Aire documentation remains available during the transition, while documentation for Calder and the upgraded Aire system is being developed on the new site.

Over time, content from this site will be migrated to Leeds HPC Docs. Once the transition is complete, this site will be retired and Leeds HPC Docs will become the main documentation site for the University of Leeds HPC systems.
:::

:::{admonition} ARC3 and ARC4 retirement
:class: note

ARC3 and ARC4 have now been retired and their hardware has been decommissioned. They are no longer available, and any data that was not moved off these systems has been lost.
:::
